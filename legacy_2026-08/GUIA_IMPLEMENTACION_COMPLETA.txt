PARTE 6: TROUBLESHOOTING
================================================================================

PROBLEMA 1: "SMD sigue siendo > 0.25 incluso con código corregido"
------------------------------------------------------------------
POSIBLES CAUSAS:
1. Distribuciones de edad muy diferentes entre grupos
2. Muestra muy pequeña
3. Caliper muy estricto

SOLUCIONES:
A. Aumentar caliper de 0.2 a 0.3 o 0.4:
   matched_data = match_and_optimize(data, 'PSEN1', 'Control', '2:1', caliper=0.3)

B. Verificar distribuciones:
   # ¿Hay overlap en edad?
   data[data['group']=='PSEN1']['age'].hist()
   data[data['group']=='Control']['age'].hist()

C. Considerar estratificación por edad:
   # Dividir en grupos etarios antes del PSM


PROBLEMA 2: "Age_Confounding = True en todos los modelos"
---------------------------------------------------------
CAUSA: El modelo está usando edad como feature discriminante

VERIFICACIÓN:
1. Revisar balance demográfico (SMD de edad debe ser < 0.1)
2. Si SMD > 0.1, el PSM no funcionó correctamente
3. Si SMD < 0.1 pero age_confounding = True:
   - La edad SÍ es un feature relevante (no confounding)
   - Esto es válido si edad está balanceada

DECISIÓN:
- Si SMD_edad < 0.1 Y Age_Confounding = True → OK, age es feature real
- Si SMD_edad > 0.1 Y Age_Confounding = True → NO OK, confusión


PROBLEMA 3: "Overfitting_Risk = HIGH"
--------------------------------------
CAUSA: Muy pocos sujetos para el número de features

SOLUCIONES:
A. Reducir features más agresivamente
B. Usar ratio mayor (2:1 en lugar de 1:1)
C. Simplificar modelo (menos hyperparameters)
D. Reportar honestamente en limitations


PROBLEMA 4: "F1 Score muy bajo (<0.3) pero AUC alto (>0.8)"
-----------------------------------------------------------
CAUSA TÍPICA: Imbalance de clases extremo + modelo predice mayoría

VERIFICACIÓN:
# Ver matriz de confusión
# Si predice casi todo como una clase → problema

SOLUCIÓN:
- Revisar class_weight='balanced' en hyperparameters
- Considerar SMOTE para oversampling
- Usar ratio más balanceado (1:1)


PROBLEMA 5: "Código corre pero no genera diagnósticos"
------------------------------------------------------
VERIFICACIÓN:
En 2_apply_psm.py, línea ~45:
    RUN_DIAGNOSTICS = True  # Debe estar en True

Si está en True pero no genera:
- Verificar permisos de escritura en directorio
- Revisar errores en consola
- Verificar que psm_diagnostics.py está en el mismo directorio

PROPUESTA DE TEXTO:

"Data Processing and Matching
------------------------------
Propensity score matching (PSM) was performed to balance demographic 
covariates between PSEN1 mutation carriers and non-carriers. Propensity 
scores were estimated using logistic regression with age and sex as 
covariates. Nearest neighbor matching with a caliper of 0.2 standard 
deviations was employed to select matched controls for each PSEN1 carrier 
[1:1 ratio / 2:1 ratio]. 

Balance assessment was conducted using standardized mean differences (SMD), 
with SMD < 0.1 indicating excellent balance and SMD < 0.25 indicating 
acceptable balance [ref: Austin 2011]. After matching, [X] PSEN1 carriers 
and [Y] controls were included, achieving excellent balance on age 
(SMD = 0.XX) and sex (SMD = 0.XX).

Machine Learning Classification
--------------------------------
Random Forest classification was performed using the matched dataset. 
Features included EEG-derived metrics (power, entropy, coherence, 
synchronization likelihood, and cross-frequency coupling) across frequency 
bands and regions of interest, as well as age, sex, and education.

Hyperparameter optimization was conducted using randomized search with 
10-fold stratified cross-validation. The final model used [X] features 
selected based on importance rankings and incremental performance evaluation. 
Model performance was assessed on a held-out test set (20% of data) using 
precision, recall, F1-score, and area under the ROC curve (AUC).

To assess overfitting risk, we calculated the ratio of training samples to 
features. Ratios ≥10 indicated low risk, 5-10 moderate risk, and <5 high 
risk. We also monitored for potential age confounding by examining feature 
importance rankings."


Referencias sugeridas:
Austin, P. C. (2011). An introduction to propensity score methods for 
reducing the effects of confounding in observational studies. 
Multivariate behavioral research, 46(3), 399-424.
